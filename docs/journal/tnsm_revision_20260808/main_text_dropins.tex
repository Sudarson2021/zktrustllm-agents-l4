\title{ZKTrustLLM-Agents: Proof-Governed Auditable Zero-Trust Control for O-RAN Edge Security}

% ABSTRACT
\begin{abstract}
Agentic automation can assist O-RAN security operations, but unconstrained
large-language-model workflows can bypass operator policy, replay evidence, and
produce decisions that cannot be audited. Existing agent frameworks provide
orchestration without jointly enforcing action admissibility, proof-bound
evidence, and reproducible evaluation. We present ZKTrustLLM-Agents, a
proof-governed zero-trust architecture that separates telemetry, reasoning,
policy, proof, and audit/anchor functions. Candidate actions pass an
AUTOMATIC--HUMAN--PRIVILEGED--NEVER ladder and are bound to hash-addressed
evidence before audit anchoring. TLC exhaustively checks six safety invariants
over 320 reachable states, and the frozen 180-cell oracle benchmark gives
Agentic RAG 100.0\% oracle-relative decision accuracy with zero unsafe automatic
executions. Across 90 matched public-testnet pairs, median first-inclusion
latency is 12.427~s on Sepolia and 7.225~s on IoTeX, with a median paired ratio
of 1.874. A live n8n run reaches a simulated ledger only after HUMAN approval.
The measured 80.5--109.8~s median decision times target Non-RT RIC/A1 policy
loops rather than Near-RT control, and the results establish properties only of
the released artifacts, synthetic oracle, testnets, and simulated actuation
path.
\end{abstract}

\paragraph{Operational timescale and intended use.}
The evaluated workflow is intended for Non-RT RIC rApps and A1 policy loops,
where security-policy decisions are made over seconds to minutes. Its measured
median end-to-end decision times (80.453--109.793~s across retrieval modes) are
therefore incompatible with Near-RT RIC xApp control and are not presented as
such. Operationally, the system is a deliberative governance and audit layer:
it can recommend or gate a policy change, preserve the evidence used, and route
sensitive actions to a human, but it is not an inline packet-processing or
sub-second radio-control mechanism.

\subsection{Claim Boundary}
The claims in this paper are restricted to the released implementation and
retained evidence. TLC establishes the stated invariants for the finite model
and explored state space, not for arbitrary implementations or deployments.
Oracle-relative metrics measure agreement with the frozen synthetic oracle;
they are not clinical, operational, or population-level accuracy estimates.
Public-testnet measurements include RPC, client, and transient network effects
and measure first inclusion rather than economic finality. The n8n demonstration
uses simulated actuation and a simulated ledger, so it does not establish
production O-RAN integration, availability, or safety. Cross-provider and
supplemental multi-agent observations describe the recorded model endpoints and
prompts at their access dates and do not imply persistence across model updates.
Unless a figure could otherwise be mistaken for production actuation or
economic finality, other sections should refer to this subsection instead of
repeating a separate disclaimer.

\paragraph{Adversarial instructions and prompt injection.}
An untrusted scenario, retrieved passage, or model response may contain text
that attempts to override the policy ladder or induce a NEVER action. The
architecture reduces, but does not eliminate, this risk by extracting a fixed
feature schema, freezing and hashing retrieved evidence, treating model output
as an untrusted proposal, reconciling proposals deterministically, and enforcing
the action ladder outside the model. Thus an injected instruction cannot by
itself authorise actuation; malformed, contradictory, or prohibited proposals
must fail closed. Prompt-injection resistance is not inferred from the benign
oracle benchmark. The accompanying 30-case suite separately tests whether
adversarial variants ever produce an executed NEVER action; its result should be
reported only after the released suite has been run against the frozen system.

Identical deployed runtime bytecode and matched payload fields do not guarantee
equal charged gas across distinct EVM-compatible chains because execution rules
and fork activation are chain-configured. The retained receipts contain gas
totals but no opcode-level traces, so the 48,973-versus-43,685 median difference

for the measured blocks.

% REPLACE THE POSITIVE SPIN ON THE 53 HTTP-500 ATTEMPTS.
The attempt index records 180 successful responses and 53 HTTP-500 responses
before retry (22.7\% of 233 attempts). The retained records do not contain
provider subcodes or end-to-end trace identifiers sufficient to distinguish
rate limiting, upstream timeouts, and n8n-side failures; root cause is therefore
unresolved. We report the attempts as workflow-boundary failures, exclude them
from accuracy denominators, and retain them to make retry and availability
behaviour inspectable. Future runs must capture provider request IDs, response
headers, exception classes, node identifiers, and timestamps.
