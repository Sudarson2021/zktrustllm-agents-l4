\subsection{Controlled Permissioned-Consensus Fault Evaluation}
\label{sec:permissioned-faults}

We replaced the protocol-only Raft and QBFT entries with controlled
multi-process experiments.  A three-member etcd cluster instantiated Raft,
whereas four local Hyperledger Besu validators instantiated QBFT and executed
the same \texttt{Stage3AnomalyLedger} bytecode used by the audit-anchor
microbenchmark.  Each reported condition retained 30 observations after three
excluded warm-ups, and the complete experiment was repeated in three
independent sessions from one clean Git commit.  Every session preserves raw
process logs, host and software metadata, contract and implementation hashes,
retained payloads, receipts and events, and a SHA-256 manifest.

The interventions deliberately distinguish protocol guarantees from the fault
behavior actually injected.  For Raft, we stopped one follower, stopped the
current leader to force an election, removed majority availability, and then
restored the cluster.  For QBFT, we stopped one of four validators and then stopped
a second validator to leave only two active participants.  After observing the
quorum-loss stall, we restored quorum and restarted the three active validator
processes to reset the exponentially backed-off QBFT round timers, following
the documented Besu recovery procedure.  We then returned the fourth validator
before collecting the recovered condition.  Stopping a validator measures process
crash/non-participation and quorum loss; it does not inject equivocation,
conflicting signed votes, state corruption, or arbitrary Byzantine messages.
Consequently, the experiment validates the operational quorum boundary but is
not labelled as a measured Byzantine-attack campaign.

\paragraph{Comparison boundary.}
Raft observations measure replicated etcd key/value writes, while QBFT
observations measure EVM execution and first inclusion of an audit-anchor
transaction.  We therefore compare conditions only within each implementation
and do not rank their absolute latencies.  These local results do not establish
economic finality, public-network behavior, or production O-RAN performance.
