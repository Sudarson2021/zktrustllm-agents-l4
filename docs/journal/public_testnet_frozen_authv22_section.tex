\subsection{Public Testnet and Frozen AuthV2.2 Proof Evidence}

To strengthen the reproducibility boundary beyond local Hardhat validation, we extended the ZKTrustLLM-Agents L4 artifact with public Sepolia deployment evidence and frozen AuthV2.2 proof artifacts. The latest AuthV2.2 trust-plane path consists of two deployable components: a BN254/Groth16-compatible verifier contract and an RBAC-controlled \texttt{DecisionAttestorAuthV2\_2} contract. The attestor is protected using OpenZeppelin \texttt{AccessControl}, where \texttt{submitDecision(...)} is restricted to accounts holding \texttt{SUBMITTER\_ROLE}. This prevents arbitrary or untrusted accounts from registering trust-plane decisions.

\subsubsection{Frozen AuthV2.2 Proof Evidence}

In addition to public testnet deployment, we generated frozen AuthV2.2 proof evidence using ZoKrates. The AuthV2.2 relation extends the previous authorization proof path by adding trust-state awareness. The circuit binds the public values \texttt{agentKey}, \texttt{capabilityId}, \texttt{policyClassHash}, \texttt{actionClass}, \texttt{contextHash}, \texttt{traceCommitment}, \texttt{expiryBucket}, \texttt{policyAdmissibilityFlag}, and \texttt{trustState}, while keeping \texttt{bindingNonce} private.

The evaluated proof instance corresponds to the bounded trust-aware admissibility case \texttt{policyAdmissibilityFlag == 1}, \texttt{trustState == 3}, and \texttt{actionClass == 3}. This represents a restricted trust state bound to an isolate action under an admissible policy decision.

The frozen proof evidence is stored in the repository under \texttt{runtime\_artifacts/l4/auth\_v2\_2/proof.frozen.json}, \texttt{runtime\_artifacts/l4/auth\_v2\_2/proof.bad.json}, and \texttt{runtime\_artifacts/l4/auth\_v2\_2/proof\_payload.auth\_v2\_2.frozen.json}. The positive proof verifies successfully in ZoKrates, while the negative proof fails verification after mutation of a public input. This provides both positive and negative reproducibility evidence for the AuthV2.2 proof path.
