# KPI Plan for Journal Validation

## Network KPIs
- RTP packets/s
- RTP jitter ms
- RTP loss %
- DTLS-RTP jitter ms
- DTLS-RTP loss %
- bitrate kbps

## Agent KPIs
- reasoning latency ms
- A2A reference size bytes
- decision class
- trust state
- human-approval queue count

## ZK KPIs
- proof version
- public inputs
- prover time ms
- verifier gas
- proof pass/fail
- mutated proof rejection

## Blockchain KPIs
- chain id
- block number
- anchor gas
- tx hash
- duplicate rejection
- zero-commitment rejection
- unauthorized submitter rejection

## Ablation KPIs
- full vs no-ZK vs no-IPFS vs RBAC-only vs oracle-only
- latency overhead
- gas overhead
- security-control coverage
